# Releases

This folder contains the released versions of the DDR VS Code extension.

## Available Versions

Download the latest `.vsix` file and follow the [Installation Guide](../docs/INSTALLATION.md).

### Latest Release

The latest stable version will be listed here once releases are published.

## Installation

1. Download the `.vsix` file for your desired version
2. Follow the installation instructions in the main [README](../README.md)

## Version History

Versions will be listed here as they are released:

```
# Format:
# - vX.Y.Z (YYYY-MM-DD) - Brief description
#   - Major changes
#   - Bug fixes
#   - Breaking changes

# Example:
# - v1.0.0 (2024-01-15) - Initial release
#   - Core DDR functionality
#   - Support for X, Y, Z features
```

## Release Notes

For detailed release notes and changelogs, see the [CHANGELOG](../CHANGELOG.md) file or individual release descriptions.

## Support

If you encounter issues with any version:
- Check the [Troubleshooting Guide](../docs/TROUBLESHOOTING.md)
- Open an issue in this repository
- Refer to the [Installation Guide](../docs/INSTALLATION.md) for help

## Platform-Specific Builds

If platform-specific builds are available, they will be named:
- `ddr-extension-{version}-win32-x64.vsix` - Windows 64-bit
- `ddr-extension-{version}-darwin-x64.vsix` - macOS Intel
- `ddr-extension-{version}-darwin-arm64.vsix` - macOS Apple Silicon
- `ddr-extension-{version}-linux-x64.vsix` - Linux 64-bit
- `ddr-extension-{version}.vsix` - Universal build

Choose the appropriate build for your system for optimal performance.
